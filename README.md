## 🥤 자판기 만들기

### 🎯 학습 목표

- 객체 간의 협력 관계를 학습합니다.
- Clean Code를 경험합니다.
- 페어를 설득하는 능력을 기릅니다.

### ✅ 기능 요구사항

> json 파일의 제품 추가는 가능하지만, 기존 제품은 수정하지 말아주세요.

1. 초기 상태 및 상품 표시

    - 프로그램 시작 시, 자판기가 보유한 전체 상품 목록을 이름, 가격, 재고와 함께 출력합니다.
    - 상품 목록 출력 후, 사용자에게 금액 투입을 요청합니다.


2. 금액 투입 및 상태 표시
    - 사용자는 금액을 투입할 수 있습니다.
    - 금액이 투입되면, 현재 투입된 금액과 함께 다시 상품 목록 및 선택 메뉴를 출력합니다.
    - 사용자는 거래 중간에 금액을 추가로 투입할 수 있으며, 금액은 계속 누적됩니다.


3. 상품 구매
    - 사용자는 상품 번호를 입력하여 상품을 구매합니다.
    - (성공 조건) 투입된 금액이 상품 가격보다 크거나 같고, 해당 상품의 재고가 1개 이상 남아있어야 합니다.
    - (성공 시) 구매한 상품과 거스름돈을 출력합니다. 해당 상품의 재고는 1만큼 감소합니다.


4. 연속 구매
    - 상품 구매 성공 후, 사용자에게 추가 구매 여부를 질문합니다.
    - 사용자가 추가 구매를 원하면, 이전 거래에서 남은 거스름돈이 현재 투입된 금액이 되어 다음 구매를 계속 진행합니다.


5. 거래 종료 및 잔액 반환
    - 사용자가 추가 구매를 원하지 않거나, 메뉴의 '금액 반환'을 선택하면 거래가 종료됩니다.
    - 거래 종료 시, 현재 남아있는 금액 전체를 거스름돈으로 반환하고 프로그램의 첫 단계(초기 금액 투입)로 돌아갑니다.


6. 예외 처리
    - 사용자가 구매할 수 없는 상황에 대해 적절히 처리하고, 사용자에게 상황을 알려주어야 합니다.

### ✍️ 프로그래밍 요구사항 & 제약사항

- Java 코드 컨벤션을 반드시 준수합니다.

- else 예약어를 사용하지 않습니다.

- 삼항 연산자를 사용하지 않습니다.

- 최소 3개 이상의 클래스로 분리하여 구현한다.

- indent(들여쓰기) depth는 2를 초과하지 않도록 메서드 내부를 구현합니다.

- 모든 메서드의 길이는 15라인을 넘지 않도록 구현합니다.

- 예외 처리: 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, 적절한 오류 메시지 출력합니다.

### 🌟 힌트

#### build.gradle 의존성 추가

```Groovy
dependencies {
    // Google Gson 라이브러리
    implementation 'com.google.code.gson:gson:2.10.1'
}
```

#### Java 파일 읽기 예시

```java

public class ItemLoader {
    // 파일 읽는 로직
    public List<Item> loadItems() {
        Gson gson = new Gson();

        // resources 폴더의 items.json 파일을 읽어옴
        InputStream inputStream = getClass().getClassLoader().getResourceAsStream("items.json");
        InputStreamReader reader = new InputStreamReader(inputStream);

        // JSON 배열을 List<Item>으로 변환
        Type itemListType = new TypeToken<List<Item>>() {
        }.getType();
        return gson.fromJson(reader, itemListType);
    }
}
```
